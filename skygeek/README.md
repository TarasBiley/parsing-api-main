# Скрипт для получения информации с сайта SkyGeek
Скрипт парсит информацию о товарах и выдаёт информацию в csv и xlsx форматах. 
При остановке и повторном запуске в том же окружении скрипт продолжит работу с места остановки.
При полной выгрузке сайт SkyGeek может замедлить ответы, что может привести к падению скрипта по таймауту по
текущему используемому ip. Перед запуском скрипта необходимо проверить, что ip не вызывает проверку 
защиты cloudflare

Для работы необходим скаченный chromedriver
